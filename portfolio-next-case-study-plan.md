# The Plan to Keep Building — Portfolio Maintenance Note

## 1. How to Add the Next Case Study

**Where it goes:**
- New project card in the `#projects` section of `portfolio.html`
- If it deserves a full write-up, create a new page at `/case-studies/<project-name>.html` and link it from the project card's "View Case Study" button

**Steps to add a new case study (reuse the three-beat shape):**
1. **Problem** — 2–3 sentences on what the project was solving or what gap it filled.
2. **What you did** — the approach, stack, and key decisions (e.g. "Built with React + Node/Express + MongoDB, integrated OpenAI API for X").
3. **What came of it** — the result: what works now, what you learned, or what impact it had.
4. Add a screenshot or short demo GIF of the real project.
5. Push to GitHub, redeploy (Netlify/Vercel auto-deploys on push to main).
